# ClearSeek / DejaVuAI — Frontend Development Case Study

**React · Next.js · TypeScript · Tailwind CSS · DaisyUI**

> **Portfolio case study only.** This repository contains no employer-owned source code, credentials, internal documentation, or confidential implementation details.

## Overview

This case study documents selected **frontend development** contributions to ClearSeek / DejaVuAI, an AI-assisted visual editing application. My work focused on interactive editing experiences and user-facing functionality.

**Role:** Frontend Developer  
**Focus:** Interactive selection tools, canvas-based editing controls, video frame workflows, and light/dark interface behavior.

## Selected Frontend Contributions

### Selection tools
- Developed and refined rectangular, freehand, lasso, and multi-selection interactions.
- Worked with normalized coordinates so selection behaviors remain consistent across visual display sizes.
- Supported selection-related user workflows and visual feedback.

### Canvas editing
- Built and refined frontend interactions for cropping, manual masking, and subject-selection workflows.
- Focused on predictable, clear controls for complex visual tasks.

### Video frame extraction
- Contributed to the user-facing workflow for extracting and selecting frames from video.

### Theme behavior
- Worked on light and dark mode UI behavior to keep tools and controls consistent across themes.

## What This Work Demonstrates

- Building complex user interactions in React and TypeScript.
- Translating visual-editing requirements into usable frontend interfaces.
- Handling coordinate-sensitive selection and canvas interactions.
- Paying attention to clarity and consistency across interface states.
